# Kindle Dashboard Renderer (Home Assistant app)

Renders a Lovelace dashboard with headless Chromium every N seconds and serves
it as an 8-bit grayscale, dithered PNG sized for a Kindle Oasis (landscape
1680x1264 by default, rotated into the device's portrait framebuffer).

See [DOCS.md](DOCS.md) for options and the
[repository README](https://github.com/LANcaster83/kindle-ha-dashboard) for
the full setup (integration + Kindle extension).
